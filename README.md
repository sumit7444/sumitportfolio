# Web Profile Project

## Overview
This Web Profile project is a personal portfolio that showcases my work, projects, and skills. It serves as a visual representation of my professional journey.

## Technologies Used
- **React**: A JavaScript library for building user interfaces.
- **Vite**: A modern build tool that provides fast and optimized development environments.
- **CSS**: For styling and layout of the webpage.
- **HTML**: The standard markup language for creating web pages.
- **JavaScript**: The programming language used for implementing dynamic features.

## Features
- Responsive design that looks great on both desktop and mobile devices.
- Interactive components showcasing different projects.
- Smooth navigation and fast loading times due to the use of Vite.

## Installation
To get started with this project, you need to have Node.js installed on your machine. You can follow the steps below:

1. Clone the repository:
   ```bash
   git clone https://github.com/sumit7444/web-profile.git
   ```
2. Navigate to the project directory:
   ```bash
   cd web-profile
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Development Setup
To start the local development server:
1. Run the following command:
   ```bash
   npm run dev
   ```
2. Open your browser and visit `http://localhost:3000`

Now, you can start developing!
